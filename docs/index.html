A small, focused trial

This page creates one Data sheet with actual string cells and Text formatting. It cannot repair digits or characters already changed upstream.

It does not create a contract or risk receipt, select numeric columns, or compare returned files. Use the Python CLI for that workflow.

Limits are checked first

UTF-8, with an optional initial BOM. Up to 10 MiB, 10,000 rows including the header, 256 columns, 250,000 cells, and 32,767 UTF-16 code units per field. Malformed CSV, ragged rows, blank lines, and unsupported control characters are rejected.

Generated XLSX: at most 10 MiB; each expanded XML part at most 20 MiB. A file within the input limits may still need splitting if its workbook exceeds those limits.

Your file stays in this tab

The page loads its code from this host. Selected CSV bytes are processed in a local browser worker; there are no processing requests, analytics, CDNs, or persistent storage. Clear or close this tab when finished.

Browser extensions and the host serving this page remain part of your trust boundary. The download contains your source values. Keep it as private as your CSV.
